# 内容 JSON 字段说明

引擎入口：`python engine/fill.py --style styles/<id> --content 内容.json --out 成品.pptx`

## 顶层

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `style` | 字符串 | 风格 id，只作记录，实际用命令行 `--style` 指定 |
| `defaults.all` | 数组 | 每一页都要先填的条目，一般不用 |
| `pages` | 数组 | 页面列表，顺序即成品顺序 |

## pages 里的一项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `page` | 整数 | 风格包里的原始页码，从 1 开始，见 `catalog.md` |
| `slots` | 数组 | 简写：按槽位号 1、2、3… 顺序填。元素是字符串、字符串数组或条目对象 |
| `map` | 数组 | 完整写法：`[{"slot": 3, "text": "..."}]`，与 `slots` 二选一 |
| `photos` | 数组 | 照片条目 `[{"photo_slot": 5, "photo": "路径.jpg"}]` |

`slots` 与 `map` 同时给时只认 `map`。

## 文字条目可覆盖的字段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text` | 字符串或数组 | 必填 | 数组的每个元素是一段 |
| `font_size` | 数字 | 参考页原字号 | 磅值。**引擎默认会在此基础上按框收小**，只在确实要更大或更小时指定 |
| `font_name` | 字符串 | 参考页原字体 | 字体名，机器上没装会回落到默认字体 |
| `bold` | 布尔 | 参考页原值 | |
| `italic` | 布尔 | 参考页原值 | |
| `color` | 字符串 | 参考页原色 | `#RRGGBB` 或 `theme:accent1` |
| `align` | 字符串 | 参考页原值 | `LEFT` / `CENTER` / `RIGHT` / `JUSTIFY` |
| `line_spacing` | 数字 | 参考页原值 | 倍数，1.2 表示 1.2 倍行距 |
| `space_after` | 数字 | 0 | 段后间距，磅 |
| `autofit` | 布尔 | `true` | 设 `false` 时按 `font_size` 原样输出，不会为了塞进框而缩字 |

## 照片条目

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `photo` | 字符串 | 图片路径，相对路径按当前工作目录解析 |
| `photo_slot` | 整数 | 照片槽编号，见 `catalog.md` 的「照片槽」行 |
| `target` | 字符串 | 与 `photo_slot` 等价，写槽位编号 |
| `crop` | 布尔 | 默认 `true`，按占位框比例居中裁切；`false` 时直接拉伸 |

照片会替换掉占位灰框，位置、尺寸、旋转角度全部沿用原框，版面不会被撑歪。

## 自动折行与自动收字号

引擎会按文本框的实际可用宽度（扣掉内边距）折行，中文按字断行、英文按词断行、标点不出现在行首。折行后如果总高度超过框高，字号按半磅递减直到放得下，最低 7 磅。

命令行会打印「字号被压缩的槽位」，同时写出 `成品.fitreport.json`：

```json
{
  "page": 2,
  "slot": 3,
  "role": "body",
  "requested_pt": 24.0,
  "fitted_pt": 20.0,
  "lines": ["折行后的第一行", "折行后的第二行"],
  "line_count": 2,
  "reference_lines": 3,
  "box_width_cm": 21.52,
  "box_height_cm": 4.84,
  "need_height_cm": 4.62,
  "shrunk": true
}
```

`shrunk` 为真就说明内容写多了。处理顺序是：先删字，再考虑换一个更大的槽位，最后才手动调小字号。

## 保留页面

`--pages` 默认 `auto`，成品只留下填过内容的页。也可以写 `1,3,5-8` 指定，或 `all` 全部保留。

## 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `槽位 7 在 slots.json 里不存在` | 槽位号写错，或用了装饰槽位的号 | 看 `catalog.md` 的表，只填表里列出的槽位 |
| `本页没有编号为 5 的照片槽` | 页码与照片槽对不上 | 看该页的「照片槽」行，或换一页 |
| 文字比周围明显小 | 内容超了，引擎自动缩了字 | 看 fitreport 的 `shrunk`，删字 |
| 某页交出来是空的 | `pages` 里没有这一页 | 补上该页，或确认本来就不需要 |
