# 复刻原理

这个 skill 不做「照着缩略图重新画一遍」，那样永远做不像。它把参考 pptx 直接当成母版，
只拆掉内容、留下外形。

## 一、外形与内容怎么分开

pptx 里每一页是一棵形状树。形状分三类：

| 类别 | 判据 | 处理 |
| --- | --- | --- |
| 文字 | 形状带文本框且有字 | 每个段落只留一个 run，把 run 的文本设为空。字体、字号、颜色、字距、行距全部保留 |
| 装饰 | 背景图、形状、弧线、页眉带、矢量图标 | 原样保留 |
| 正片 | 证书截图、别人的图表、别人的照片 | 证书图表直接删；照片换成同位置同尺寸的灰框 |

装饰性的大数字、章节序号（超过 20 磅且只有一两个字）不参与清空，它是版式的一部分，
清掉就少一块视觉重量。

分离之后得到的 pack.pptx 就是「一套空壳版面」：外观 100% 等于参考件，没有任何别人的内容。

## 二、槽位怎么记住

清空文字后，形状里已经没有字可以用来找它了。所以槽位用 shape_id 定位——那个编号写在
XML 里，保存、复制、LibreOffice 往返都不会变。

`make_pack.py` 把每个文字槽的信息写进 slots.json：

```json
{
  "slot": 3,
  "shape_id": 30,
  "role": "body",
  "left": 1.08, "top": 8.04, "width": 22.03, "height": 5.09,
  "insets": [0.254, 0.254, 0.127, 0.127],
  "line_spacing": 1.0,
  "paragraphs": 3,
  "font_name": "阿里妈妈数黑体",
  "font_size": 24.0,
  "color": "#FFFFFF",
  "sample": "小时候，家里有一截裸露的空调管道..."
}
```

保留 `sample` 是为了让写内容的人知道这个槽原来装多少字、装什么样的话。

## 三、文字怎么塞得下

参考页的文本框是给原来的文字量的，新内容一旦更长更宽，就会钻到压在上层的装饰图形底下。

`fit.py` 分三步处理：

1. **量宽**：CJK 按全角算，拉丁字母、数字、标点按实测比例折算，再乘 1.04 安全系数。
2. **折行**：按文本框扣掉内边距后的实际宽度做贪心折行。中文按字断，英文按词断，逗号句号不出现在行首，左括号不出现在行尾。
3. **收字号**：折行后算总高度，超过框高就按半磅递减，直到放得下，最低 7 磅。

每次都会写一份 fitreport，明确标出哪些槽被缩了字。被缩字等于内容写超了，处理办法是删字，
不是继续缩。

## 四、字体怎么办

参考件常常内嵌字体（`ppt/fonts/*.fntdata`），一份就有几十兆。风格包默认去掉内嵌字体，
只保留字体名。机器上装了同名字体就照常显示，没装则回落到系统字体。

本机已装的常用中文字体：

- 思源黑体、思源宋体（Heavy / Medium / Bold）
- 微软雅黑、等线、黑体、宋体、楷体
- 华文行楷、华文楷体

参考件里常见的商业字体（阿里妈妈数黑体、汉仪黑方、庞门正道粗书体、演示流云楷、OPSans、
方正小标宋）多数机器没装，会回落。回落不影响版面，只影响字形气质。

## 五、照片怎么处理

别人的照片不能直接留在成品里。判据看图片本身，不看尺寸：

- 大面积白底（近白像素超过 35%）或极低饱和度 → 截图、证书、表格，整块删掉
- 平均亮度极高 → 白底文档，删掉
- 满幅彩色 → 照片，换成同位置同尺寸的灰框

判错代价不对称：把别人的证书留在成品里，等于把别人的材料抄进了新 PPT。所以宁可多删。

使用者填照片时，`fill.py` 按占位框的长宽比居中裁切，不会把照片拉变形。

## 六、为什么不用「重新绘制」

用 python-pptx 从零画一份长得像的版面，需要复刻每一根弧线、每一层渐变、每一张背景图。
参考件的装饰大量是 freeform 自由曲线与图层叠加，重画既做不到一致，也无法维护。

直接拿参考件当母版，外观天然 100% 一致，工作量集中在文字与照片的替换上。

## 七、页面适配度

参考件里不是每一页都适合换别人的内容。有些页的形状是照着原作者那段话画的：

- 「目录」页的四个色块，刻度是按原作者的四个章节名定的。
- 心理测评页（霍兰德六边形、MBTI 四字母）本身就在画一个特定结论。
- 校园合影、校门照片是学校专属的。

`make_pack.py` 给每页算一个 `specificity`：

| 值 | 含义 | 处理 |
| --- | --- | --- |
| `generic` | 色块、分区、箭头、时间轴这类通用版面 | 优先选 |
| `mixed` | 文本里出现少量专属词 | 次选 |
| `specific` | 目录、测评图、校门合影这类为特定内容画的 | 尽量避开 |

`plan.py` 按 `generic` > `mixed` > `specific` 的顺序挑页。实在只能用 `specific` 页时，
大纲会明确提示「用的是偏专属的版面，填完务必看缩略图」。

这条机制只是缓解，不能根治：如果某个风格包的专属页比例太高，换一个风格包更省事。

### 图里印着字的页，清空文字去不掉

最麻烦的一类：封面与章节页的主标题不是文本框，而是设计时导出成一整张图片贴上去的书法字
或艺术字。清空文字管不到像素，那些字会原样留在成品里。

`make_pack.py` 会把这类图换成同位置的可填标题框，但只对**单独一行的标题图**有效。如果整套
版的封面本身就是「一整张已经排好字的图」（背景、装饰、标题全在一张 PNG 里），那就没有任何
办法复刻。

`engine/verify_styles.py` 会标出每个风格包能不能用于封面：

```
t-slate-serious   全篇可用
t-warm-orange     仅内页可用（封面主标题是图）
```

标「仅内页可用」的包，封面另找图，或者只用它做内页。

## 八、这种做法的边界

- 参考件的版式是为它的内容设计的。内容差异太大时，硬套会出现「一句话占满整块正文区」的尴尬。挑页时要看缩略图，选版面能装下的那页。
- 参考件的页数固定。内容讲不到那么多页就少填几页，成品会自动只保留填过的页。
- 参考件用到特殊字体时，装了才像，没装会回落。
