# 量化判据手册

这套判据把「图好不好看」拆成可以复核的数字。每一条都有阈值、单位与判定方式，
脚本给出实测值与阈值，读者自己判断差多少。

## 口径档位

同一份 PPT 在不同场合的可读性要求不同，所以字号下限按档位取值。命令行用
`--profile` 指定，默认 `presentation`。

| 角色 | presentation（投影讲解） | reading（屏幕自读） | paper（对齐论文画图） |
| --- | --- | --- | --- |
| display | 36pt | 24pt | 8pt |
| headline | 24pt | 16pt | 8pt |
| title | 18pt | 12pt | 8pt |
| body | 16pt | 10pt | 8pt |
| text | 14pt | 9pt | 8pt |
| label | 12pt | 8pt | 8pt |
| backdrop_note | 12pt | 8pt | 8pt |
| glyph | 12pt | 8pt | 8pt |
| chrome（页眉导航） | 10pt | 7pt | 8pt |

presentation 档按 33.87 × 19.05 cm（16:9 宽屏）投影到 2 米宽幕布、观众坐在 8 米外
的可读性定。reading 档按 1080p 屏幕上自读定。paper 档沿用论文画图的 8 磅下限，
用于把 PPT 页面当论文插图导出时。

## 版面门（gate_layout.py）

| 判据 | 阈值 | 单位 | 等级 | 判定方式 |
| --- | --- | --- | --- | --- |
| 越界（文字框） | 0.05 | cm | FAIL | 文字框超出页面边界的最大距离 |
| 越界（图片） | 3.0 | cm | WARN | 装饰图出血超过这个幅度才算缺陷 |
| 页边留白 | 0.25 | cm | WARN | 文字框距页面四边的最小距离，页眉导航不参与 |
| 溢出 | 8% | 比例 | FAIL | fit 估算所需高度超过框内可用高度的幅度 |
| 遮挡 | 25% | 面积比 | WARN | 上层不透明形状覆盖文字框面积的比例 |
| 重叠 | 30% | 面积比 | FAIL | 两个文字框互相覆盖占较小框的比例 |
| 字号下限 | 见上表 | pt | FAIL | 实际字号（含 normAutofit 缩放）低于角色下限 |
| 自动缩字 | 0.90 | 倍率 | WARN | normAutofit 的 fontScale 低于这个值 |
| 层级 | 1.2 | 倍率 | WARN | 页面主标题字号 ÷ 正文字号 |
| 行数 | 6 | 行 | WARN | 正文折行后的行数 |
| 居中 | 0.15 | cm | WARN | 文字框中点与底衬框中点的最大偏差 |
| 变形 | 5% | 比例 | WARN | 图片框长宽比与源图长宽比的偏差（未裁切时） |

三条排除规则，都是为了避免把正常版式判成缺陷：

- **遮挡记告警不记失败。** 组合版式里上层色块常是文字的高亮底衬，几何判断分不清「压在文字上」与「垫在文字下」，只能靠看图确认。
- **开了 normAutofit 的文本框不查溢出。** PowerPoint 自己会缩字，缩字结果由字号下限判据负责。
- **满版背景图不算遮挡。** 文字本来就压在背景上。
- **居中只对「一个底衬框里只装一个文字框、且底衬面积不超过文字框 1.8 倍」的槽位生效。** 一个卡片里同时放标题与正文是常见版式，正文本来就该排在标题下方。

## 内容门（gate_content.py）

| 判据 | 阈值 | 判定方式 |
| --- | --- | --- |
| 页存在 | — | 内容引用的页必须在风格包里 |
| 槽位存在 | — | 内容引用的槽位号必须在该页的 slots.json 里 |
| 展示槽字数 | 1.5 倍 | display/headline/glyph 槽，新字数 ÷ 参考字数 |
| 标签槽字数 | 2.0 倍 | label 槽，超出只告警 |
| 正文槽字数 | 2.5 倍 | body/text/title 槽 |
| 每段字数 | 2.0 倍 | 单段字数 ÷ 参考每段字数，超出告警 |
| 字号下限 | 见口径表 | fit 算出的 fitted_pt |
| 缩字幅度 | 20% / 35% | 相对请求字号的降幅，20% 告警、35% 失败 |
| 页面字数 | 220 字 | 单页可见文字总字数，超出告警 |
| 照片存在 | — | 内容声明的照片文件必须存在 |
| 照片空缺 | — | 有照片槽却未填，告警 |
| 封面/章节标题 | — | cover 与 section 页必须填 headline 槽 |
| 章节页正文 | — | section 页填了正文，告警 |
| 重复填槽 | — | 同一页同一槽位填两次 |

## 配色门（gate_palette.py）

| 判据 | 阈值 | 判定方式 |
| --- | --- | --- |
| 色觉缺陷可混淆 | deltaE < 12 | Machado 2009 矩阵模拟 protanopia / deuteranopia / tritanopia，CIELAB 下算 CIE76 |
| 灰度可混淆 | 亮度差 < 0.03 | Rec.709 亮度 0.2126R + 0.7152G + 0.0722B |
| 对比度失败 | 4.5 | WCAG 相对亮度比，正文对背景 |
| 对比度告警 | 7.0 | 同上 |
| 单页配色数 | 6 | 一页上不同颜色的数量上限，沿用 Paul Tol 亮色板口径 |

Paul Tol bright 亮色板：蓝 `#4477AA`、青 `#66CCEE`、绿 `#228833`、黄 `#CCBB44`、
红 `#EE6677`、紫 `#AA3377`、灰 `#BBBBBB`。红只用于问题与失败。

## 导出件门（gate_exports.py）

| 判据 | 阈值 | 判定方式 |
| --- | --- | --- |
| 文件存在 | — | 路径存在且非 0 字节 |
| 签名一致 | — | png `89 50 4E 47 0D 0A 1A 0A`、pdf `%PDF`、jpeg `FF D8 FF`、svg 含 `<svg` |
| 栅格 dpi | 声明值 | Pillow 读 `image.info["dpi"]`，容差 1.0 |
| PDF 页数 | 声明值 | pymupdf 优先，取不到时正则数 `/Type /Page` |
| 单边像素 | 8192 | PNG 单边上限，超出告警（审阅时 read_image 读不进来） |
| 文件体积 | 20 MB | 单张栅格上限，超出告警 |

## 数字门（gate_numbers.py）

页面上的每个数字都要能在证据文件里找到出处。这条对应论文画图的「每个绘图数字配一份
_source_data.csv」。

| 判据 | 判定方式 |
| --- | --- |
| 数字可追溯 | 页面里的数字字面量必须出现在证据文件抽取出的数字集合里 |
| 证据格式 | `.csv` 每格都算；`.json` 递归取全部数值；`.md`/`.txt` 正则抽数字字面量 |
| 不参与追溯 | 序号（1 到 10）、年份与年月日、班级与学号这类标识符、页眉导航里的数字 |
| 默认等级 | 对成品 pptx 默认 WARN（大量装饰数字无法追溯），对内容 JSON 可用 FAIL |

## 规格门（gate_spec.py）

非数据图的「先填 figure-spec 再画」搬到 PPT：每页填内容之前先有 spec。

| 判据 | 判定方式 |
| --- | --- |
| spec 存在 | `slide_specs/spec_pNN.md` 必须存在 |
| 小节齐全 | 主张、内容、槽位上限、状态四节 |
| 主张非空 | 不能是「待填」「TODO」「TBD」 |
| spec_complete | 必须是 `Y` |

`spec_complete=Y` 之前不许生成成品，这条与论文画图的 `spec_complete=Y 之前不许作图` 同一条纪律。

## 判定纪律

- 失败（FAIL）表示必须改；告警（WARN）表示知道就行，改不改自己判断。
- 不为了全绿而放宽阈值。阈值放宽之后判据就失去意义，等于没做。
- 每一处失败都报出实测值与阈值，读者自己看差多少。
- 门是外部信号。不靠「我觉得这页没问题」收尾，靠门通过收尾。
