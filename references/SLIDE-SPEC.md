# Slide Spec（页面规格契约）

> **用途**：每一页在**填内容之前**先填本 spec。页面只是 spec 的渲染；结构在 spec 里先冻结，
> 杜绝「页面与讲稿矛盾」「页面塞进正文没说的东西」。spec 存为 `slide_specs/spec_pNN.md`，
> 与内容 JSON、成品、质检报告同目录可追溯。
>
> **spec_complete=Y 之前不许生成成品。** 与论文画图的 `spec_complete=Y 之前不许作图` 同一条纪律。

## 主张

- **主张**：这页要让读者记住的一句话（必须能在一份证据文件里找到对应条目，找不到就删这页）
- **叙事角色**：开场 / 机制说明 / 结果展示 / 收束
- **证据来源**：哪个文件、哪次实验、哪个数据表；没有数据就写「无数据」

## 内容

- **页面标题**：不超过 12 字
- **正文要点**：一行一个要点，每个要点只说一件事
- **数据**：页面上出现的每个数字，写清它来自哪份文件的哪一行

## 槽位上限

- **页面尺寸**：从风格包的 slots.json 或 pptx 读出，单位厘米
- **口径**：presentation / reading / paper，决定字号下限
- **字号下限**：按角色查 `references/QUANT-RULES.md` 的口径表
- **最多正文行数**：6 行（presentation 档）
- **最多页面字数**：220 字（presentation 档）
- **可填槽位**：从 `catalog.md` 抄下这页的槽位号与参考字数，超出上限的门会拦

## 照片

- **照片槽**：无 / 槽位编号
- **照片来源**：自己的照片路径。空着的灰框交出去等于没做完，必须填满或用 `--pages` 删掉这页
- **裁切方式**：按占位框比例居中裁切（默认），或写明需要完整显示

## 状态

- **spec_complete**：Y/N
- **generated**：Y/N + 日期 + 命令
- **reviewed**：Y/N + 过门日期
