# 同类工具调研与赛事依据

写这个 skill 之前查过现有的 PPT skill 与三个赛事的官方口径，这里记录结论与出处。

## 一、现有 PPT skill 都在解决什么问题

搜到的同类工具，路线分两类。

**原生 PPTX 路线**（与本 skill 最接近）

- `sunchaokun/PPT-Design-Skill`：强调像素级控制与完全可编辑的 pptx，覆盖大量风格。
- `Brusdeylins/ppt-skill`：面向 LLM agent 的确定性 pptx 工具链，模板感知的创建与编辑，操作有 schema 校验。
- `XDZ666666/claude-code-ppt-skill`：通过 COM 自动化实时构建演示文稿。
- `kdnsna/ultimate-ppt-master-skill`：从需求分析到视觉方向选择再到交付的完整流程。

**HTML 幻灯片路线**

- `lewislulu/html-ppt-skill`：24 个主题、31 种版式、20 多个动画的 HTML 演示工作室。
- `op7418/NanoBanana-PPT-Skills`：以 AI 生成整页图片为主，配合转场与交互播放。

目录类汇总：`brycewang-stanford/many-ppt-skills`（按 HTML 与原生 PPTX 两条路线对比）、`ningzimu/awesome-ai-ppt`。

### 结论

这些工具解决的都是「怎么把内容排得好看」，没有一个是「怎么把内容排成某个具体赛事评委想看的样子」。它们的风格库是通用商务风，不区分赛道。

本 skill 的差异点有两处：

1. **外形来自真实获奖作品，而不是设计出来的模板。** 直接拿往届参赛 pptx 当母版，清空文字保留版面，外观天然一致。
2. **叙事来自赛事评审口径。** 先按赛道的考察重点排大纲，再从版面库里挑页，避免「有版式没逻辑」。

## 二、三个赛事的官方口径

### 全国大学生职业规划大赛

依据：教育部《关于举办第四届全国大学生职业规划大赛的通知》（2026 年 10 月 8 日）及其附件。

- **成长赛道**：面向本专科非毕业年级。考察树立生涯发展理念并合理设置职业目标、围绕目标持续行动并不断调整的成长过程，通过学习实践提升综合素质与专业能力，体现正确的择业就业观念。
- **就业赛道**：面向本专科高年级计划求职学生与研究生。考察求职实战能力，个人综合素质、专业能力与目标职业的契合度，个人发展路径与就业市场需求的适应度。
- **赛制**：校赛、省赛、全国总决赛三级。总决赛约 800 人，成长赛道约 450 人、就业赛道约 350 人。

对应到 PPT 骨架，成长赛道围绕「理念、目标、行动、调整、提升」五件事，就业赛道围绕「求职实战、契合度、适应度」。

来源：
- 教育部通知 http://www.moe.gov.cn/srcsite/A15/s7063/202610/t20261010_1453481.html
- 首届成长赛道方案 https://www.ncss.cn/news/file.do?method=downFile&id=2293116159

### 挑战杯 / 中国国际大学生创新大赛

两赛的创业计划类评审都围绕同几条主线：项目背景与痛点、产品与技术创新、市场与竞争、商业模式与财务、团队与执行。路演时长通常 5 到 8 分钟。

上海海事大学教务处的赛事培训通知把这一结构讲得最直接：路演 PPT 要「从项目背景、商业模式、财务分析等多个关键维度」展开，要求「清晰的逻辑、鲜明的观点、精炼的文字、美观的视觉效果」。

来源：
- 上海海事大学培训通知 https://jwc.shmtu.edu.cn/2025/0314/c8546a242276/page.htm
- 挑战杯创业计划竞赛章程 http://hs.nufe.edu.cn/_upload/article/files/a6/14/da2860394596b233923a1851d0a4/6f783d32-3517-48ca-b4cf-fa38d8d72637.pdf
- 中国国际大学生创新大赛通知 http://www.moe.gov.cn/srcsite/A08/s5672/202607/t20260731_1445670.html

通用路演结构（多份攻略一致）：封面、痛点、解决方案、市场分析、商业模式、团队、融资计划、愿景。

## 三、这些结论怎么用进 skill

`engine/plan.py` 把上面三套骨架写成代码：

```bash
python engine/plan.py --list
python engine/plan.py --style styles/t-warm-orange --event 职业规划成长 --out 大纲.json
```

大纲给出每页的章节名与内容提示，并按版面类型匹配风格包里的具体页码。某种版面不够用时，它会明确列出「没有某版面，改用某页」或「已跳过」，不会静默丢页。

## 四、没做的事

- 没有下载任何商业模板站的付费模板。风格包全部来自用户提供的往届参赛文件。
- 没有把网上的路演稿文案抄进来。文案规则写在 `references/WRITING-RULES.md`，要求写使用者自己的真实经历。
