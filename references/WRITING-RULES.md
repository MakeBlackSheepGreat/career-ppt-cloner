# 写文案的规矩

这套 PPT 的外形照抄往届，文字必须是使用者自己的真实经历。外形可以抄，内容不能。

## 语气

- 第一人称，用「我」，不用「本人」「笔者」。
- 短句为主。一句话讲一件事，讲完就断。
- 写具体做过的事、用过的工具、遇到的问题。不写「提升了能力」「锻炼了自我」这类没有信息量的句子。
- 不用宣传语腔调。不用「赋能」「抓手」「闭环」「顶层设计」「多维度协同」这类词。

## 禁用清单

以下说法一律改写：

| 不要写 | 改成 |
| --- | --- |
| 提升了自己的综合能力 | 写清做了哪件事，学会了哪个工具，花了多久 |
| 不断突破自我 | 写具体的一次失败和它怎么被解决 |
| 为未来打下坚实基础 | 写下一步要做的具体动作 |
| 具有强烈的社会责任感 | 写参加过哪次服务，做了什么 |
| 深入贯彻…精神 | 一般不写进学生 PPT |
| 收束成职业主线 / 路径落地 / 持续复盘 | 直接写学科、项目、岗位、下一步行动 |

## 页面文字的写法

- **页标题**：不超过 12 字，用自然表达。写成「转专业背景」「兴趣积累」「职业目标与行动计划」，不写「我的专业选择之路」。
- **正文段**：每段 1 到 2 句，总字数按 `catalog.md` 里「参考字数」列的七成到十成写。
- **短标签**：四到八字，并列的几项字数尽量一致，视觉才齐。
- **压轴句**：一句话，不超过 20 字，讲这页想说清的那件事。

## 职业规划大赛的常见结构

成长赛道通常四段：

1. 起点：一件具体的小事，说明兴趣从哪来。
2. 探索：做了哪些尝试，遇到什么问题。
3. 目标：想做什么岗位，为什么是这个。
4. 行动：接下来一到三年准备怎么做，具体到课程、项目、实习。

就业赛道通常四段：

1. 个人基本情况与求职意向。
2. 岗位认知：这个岗位每天在做什么，要求什么。
3. 能力匹配：自己哪些经历对上了这些要求。
4. 职业规划：入职后一到三年的打算。

对应到风格包，章节页一页一个段落，图文页一页一个论点。

## 讲稿

讲稿不进页面。页面只放短句和关键数字，讲出来的部分另写。

## 交付前自查

- 每一句都能说出对应的事实来源吗？不能就删。
- 有没有哪一页的文字在讲另一页的事？
- 数字有没有出处？比赛名次、项目规模、时长都要能对上材料。
