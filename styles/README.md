# 风格包索引

每个子目录是一套从往届参赛作品里抽出来的风格。`pack.pptx` 里已经清空全部文字、
删掉别人的证书与图表、把照片换成了灰框，外观与参考件一致。

写内容前先打开对应目录的 `catalog.md`，那里有每页缩略图与槽位表。

| 目录 | 名称 | 外形 | 适合 |
| --- | --- | --- | --- |
| t-warm-orange | 橙暖生活 | 夜色家居背景，橙金弧形色块，页眉深色标题条加橙金进度条 | 成长赛道，温情叙事，从兴趣起点讲到成长 |
| t-teal-tech | 青蓝科技 | 青蓝渐变城市天际线，整页大数字章节页，白底胶囊条正文 | 就业赛道，理工科技术岗 |
| t-slate-serious | 深蓝严谨 | 深色星空与机器人主视觉，顶部四段导航常驻 | 研究生就业赛道，科研项目密集 |
| t-red-formal | 赤红正式 | 红金对称构图，书法主标题，金色分隔线 | 正式汇报感强，金融与管理方向 |
| t-green-eco | 墨绿实业 | 墨绿配米色，稳重克制，几何色块分区 | 行业落地型叙事，新能源与制造 |
| t-blue-academic | 靛蓝学术 | 蓝白插画，顶部导航条常驻 | 成长赛道四段式（探索、目标、匹配、行动） |
| t-tech-deck | 科技深景 | 深色科技底，亮蓝描边卡片 | 硬件项目与竞赛成果为主 |

## 每个风格包里有什么

| 文件 | 用途 |
| --- | --- |
| pack.pptx | 空壳版面，全部文字已清空 |
| slots.json | 每个文字槽的位置、尺寸、字体、行距、底衬中心 |
| catalog.md | 页面目录：缩略图、页面类型、可填槽位表、照片槽编号 |
| thumbs/ | 每页缩略图 |
| meta.json | 风格元信息：来源、页数、每页类型 |

## 怎么选

1. 先看赛道：成长赛道选 t-warm-orange、t-blue-academic；就业赛道选 t-teal-tech、t-slate-serious、t-green-eco。
2. 再看内容密度：科研项目与竞赛证书多，选 t-slate-serious 或 t-tech-deck；以叙事为主，选 t-warm-orange。
3. 最后看专业气质：理工科配青蓝或深色，人文社科配赤红或墨绿。

## 加新风格

```bash
python engine/build_style.py --src 参考.pptx --outdir styles/<新id> --name "名字" --tier A --note "外形一句话描述"
```

抽完先看 `catalog.md` 里的缩略图，确认版式确实可用再写内容。
